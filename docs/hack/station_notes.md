# The ranger station's B1F notes: for editing

Five explorers' notes on B1F (the clock room). Together they give the time to set on the clock: **4:15 a.m.** Each
note carries one hint, and no two hint at the same thing. If you change a hint, keep the set adding up to one
time, or tell me the new time and I'll change the puzzle to match.

Each `---` is a new text box. A box shows two lines (a third scrolls up in the same box); a line fits about 208
pixels, roughly 32-38 characters. I'll measure and rewrap if needed.

They now lie in the rooms round the clock room (office, lab, greenhouse, study, the statue hall). Where each one
is listed below; that can change too. Source: `data/maps/RangerStation_B1F/scripts.inc`.

## Note 1 (`RangerStation_B1F_Text_Note1`)

*Hint: Night (only the stars were out). Spot: the greenhouse (among the plants).*

A torn page from a notebook…

in. Only the stars lit the trail
through the WOODS.”

stairs. Some ranger I'd make.
-TOM”
